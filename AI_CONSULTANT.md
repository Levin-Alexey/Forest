# Документация: AI Консультант (Гибридный подход)

## Описание

Модуль AI консультанта позволяет пользователям общаться с искусственным интеллектом через N8N webhook.

**Гибридный подход:**
- 🤖 **По умолчанию** - любое текстовое сообщение отправляется в AI (если нет активных форм)
- 📝 **Приоритет FSM** - если пользователь заполняет форму (заявка, номер телефона), сообщения обрабатываются соответствующим handler'ом
- 🔘 **Кнопка "AI консультант"** - информационная, показывает что AI активен и готов к общению

## Как это работает

### 1. Обычное общение (режим по умолчанию)

Пользователь просто **пишет сообщение** в чат → бот отправляет в N8N → возвращает ответ AI.

**Не требуется** нажимать кнопку для активации!

### 2. Кнопка "🤖 AI консультант"

- Информационная кнопка (для наглядности)
- При нажатии показывает подсказку о работе с AI
- Подтверждает, что AI готов принимать вопросы

### 3. Режим заполнения форм (приоритет FSM)

Когда пользователь заполняет форму (например, оставляет заявку):
- Бот переходит в специальное FSM состояние
- Текстовые сообщения обрабатываются handler'ом формы
- AI **НЕ** получает эти сообщения
- После завершения формы → возврат в режим AI по умолчанию

### `main.py`

Главный обработчик текстовых сообщений:

```python

async def text_message_handler(message: Message, state: FSMContext):
    """
    ГИБРИДНЫЙ ПОДХОД:
    - Если есть активное FSM состояние → пропускаем (обработает соответствующий handler)
    - Если НЕТ активного состояния → отправляем в AI по умолчанию
    """
    current_state = await state.get_state()
    
    if current_state is None:
        # Нет активных форм → отправляем в AI
        await send_to_ai_and_reply(message)
```

### Формат запроса в N8N

```json

    "message": "текст сообщения пользователя",
    "user_id": 123456789,
    "chat_id": 123456789
}
```

### Формат ответа от N8N

N8N должен быть настроен на **"Respond With: Text"** и возвращать текстовый ответ.

## FSM (Finite State Machine)

Бот использует aiogram FSM для управления состояниями:

- **None** (по умолчанию) - **AI АКТИВЕН**, все текстовые сообщения отправляются в N8N
- **ApplicationForm.*** - заполнение формы заявки, AI отключен
- **ContactForm.waiting_for_phone** - ввод телефона, AI отключен
- **Другие состояния форм** - AI отключен, приоритет у обработчика формы

### Приоритет обработчиков:
1. **Специфичные FSM состояния** (формы) - обрабатываются первыми
2. **Обработчик по умолчанию** (AI) - срабатывает если состояние = None

## Примеры использования

### Сценарий 1: Обычное общение (без нажатия кнопки)

1. Пользователь: `/start` → видит главное меню
2. Пользователь: "Привет, расскажи про проект"
3. Бот: [статус "печатает..."] → ответ от N8N AI
4. Пользователь: "Какие цены?"
5. Бот: [ответ от AI]

**AI работает по умолчанию!**

### Сценарий 2: Нажатие кнопки "AI консультант"

1. Пользователь: нажимает "🤖 AI консультант"
2. Бот: "🤖 Привет! Я AI консультант. Просто напишите ваш вопрос, и я постараюсь помочь! 💬"
3. Пользователь: "Расскажи про локацию"
4. Бот: [ответ от AI]

**Кнопка информационная, не меняет поведение**

### Сценарий 3: Заполнение формы (AI отключен)

1. Пользователь: нажимает "Оставить заявку"
2. Бот: "Введите ваше имя" (FSM = ApplicationForm.waiting_for_name)
3. Пользователь: "Иван" 
4. Бот: "Введите телефон" (**НЕ отправляет в AI!**)
5. Пользователь: "+79991234567"
6. Бот: "Спасибо! Заявка принята" (FSM сбрасывается → None)
7. Пользователь: "Спасибо!"
8. Бот: [ответ от AI] (**AI снова активен!**)

## Безопасность

- Webhook URL хранится в переменных окружения
- Ошибки логируются, но не показываются пользователю
